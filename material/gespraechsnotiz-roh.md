# Gesprächsnotiz (roh): Bedarfsgespräch Rheinpark

Fiktives Unternehmen, alle Angaben erfunden. Auch alle Personen, Telefonnummern und Mailadressen sind erfunden. Die Telefonnummern stammen aus den Rufnummern, die die Bundesnetzagentur für Medienproduktionen freihält („Drama Numbers“, https://www.bundesnetzagentur.de/DE/Fachthemen/Telekommunikation/Nummerierung/DramaNumbers/artikel.html, abgerufen am 23.11.2026).

Notiz vom 01.12.2026 (Dienstag) · Rohnotiz für Lab 4.3 (Gesprächsnotiz von Hand mit KI ins CRM) und Lab 9.1 (derselbe Ablauf als Workflow). Der Tag der Notiz ist zugleich der Stichtag der Übungsdaten: „bis Fr.“ = Freitag, 04.12.2026, „Mo nä. Wo.“ = Montag, 07.12.2026. So sieht eine echte Notiz direkt nach dem Termin aus: Stichpunkte, Abkürzungen, keine Ordnung.

## Abkürzungen in der Notiz

| Kürzel | Bedeutung |
| --- | --- |
| GF | Geschäftsführung |
| BR | Besprechungsraum |
| DB | Doppelbuchung |
| VC | Videokonferenz |
| AP | Ansprechperson |
| SSO | Single Sign-on (Anmeldung mit dem Firmenkonto) |
| AVV | Auftragsverarbeitungsvertrag (Datenschutzvertrag nach DSGVO) |
| MA / HW / OG | Mitarbeitende / Hardware / Obergeschoss |
| WV | Wiedervorlage |
